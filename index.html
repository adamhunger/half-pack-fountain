Half-Pack Fountain

Each particle's velocity is two 16-bit floats packed into one u32 with TSL's packHalf2x16. The compute shader unpacks it, does the physics in f32, and packs it again every frame. This needs no shader-f16 and runs on the WebGL 2 fallback too.

The TSL that runs it

const velocities = instancedArray( COUNT, 'uint' );   // two halves per element

const update = Fn( () => {
  const packed = velocities.element( instanceIndex );
  const vel = unpackHalf2x16( packed ).toVar();      // vec2, f32 math from here

  vel.assign( vel.add( vec2( 0, gravity.negate().mul( dt ) ) ) );
  // … pointer push, damping, move position, respawn …

  packed.assign( packHalf2x16( vel ) );               // back to 16 + 16 bits
} )().compute( COUNT );

// material reads the same buffer
material.colorNode = speedColor( unpackHalf2x16( velocities.element( instanceIndex ) ).length() );
